# ⏳ Countdown Timer

A clean and interactive countdown timer built with HTML, CSS, and JavaScript.

## 🔗 Live Demo
[View Countdown Timer](https://ioana2803.github.io/countdown/)

## ✨ Features
- Set a custom time (hours, minutes, seconds)
- Displays time in HH:MM:SS format inside a circular UI
- Start, Pause, and Reset controls
- Progress indicator (percentage remaining)
- Clean blue gradient design

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla)
